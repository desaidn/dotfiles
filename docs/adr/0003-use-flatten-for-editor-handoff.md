# Use flatten.nvim for editor handoff

Terminal tools launched from Neovim should return to the host Neovim through flatten.nvim instead of bespoke editor wrappers. The shell owns the global editor contract by setting `EDITOR`, `VISUAL`, and `GIT_EDITOR` to `nvim`. The shared terminal-tool module owns the source marker, opaque flatten payload, and per-tool handoff policy so individual tools and flatten do not duplicate routing knowledge.

Neovim-owned terminal flows should use the shared `nvim/lua/custom/lib/terminal_tool.lua` launcher: one persistent terminal job per tool, restarted when its effective working directory changes, shown in a Neovim float in every environment with live sizing to its launching window, host tmux prefix and pane navigation kept upstream, shell-owned editor variables, and flatten.nvim handoff. New tools should be declarative `create` calls containing only their stable id, command, key, description, and optional environment or exceptional handoff policy unless they have a genuinely different job.
