# Port kickstart with vim.pack while preserving modular config

The Neovim config will adopt kickstart.nvim's native `vim.pack` plugin management and modern Lua section style, but it will keep this repo's modular layout instead of moving back to upstream kickstart's single-file shape. The upstream single-file form is useful for teaching, while this repo's modules preserve the established Code Interface boundaries around search, Git transaction surfaces, review surfaces, terminal-tool handoff, language tooling, and no-icon UI preferences. This is a pure refactor, performance improvement, and upstream-practice adoption: port useful kickstart mainline patterns without changing the established flow. Native package management should stay simple and idiomatic: do not recreate lazy.nvim's trigger DSL, only add explicit on-demand `packadd` wrappers where they make the config clearer, commit `nvim/nvim-pack-lock.json` as the plugin lockfile instead of keeping `nvim/lazy-lock.json`, and require the latest kickstart mainline Neovim baseline with no lazy.nvim fallback.
