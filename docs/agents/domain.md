# Domain Docs

This repo uses a single-context layout.

Before using engineering skills, read `CONTEXT.md` at the repo root if it exists, then read relevant ADRs under `docs/adr/` if they exist.

If those files do not exist, proceed silently. The domain-modeling workflow creates them lazily when useful.

When output names a project concept, use the vocabulary from `CONTEXT.md`. If an output contradicts an ADR, flag that conflict explicitly.
